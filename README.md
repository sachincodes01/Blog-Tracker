**Blog Tracker**

Blog Tracker is a production-ready WordPress plugin that helps developers and site owners track Gutenberg block usage across posts and pages.

**Features**

Detect Gutenberg block usage
Search and filter blocks
Export block usage as CSV
Quick access to edit pages using blocks
Supports core, ACF, and custom blocks
Real-time scanning on post save
Clean WordPress admin dashboard
Installation
Upload the plugin to /wp-content/plugins/
Activate the plugin
Open Block Usage in WordPress admin
Click Rescan Blocks
